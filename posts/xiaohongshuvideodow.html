通过jq命令行工具解析小红书无水印视频

作者：@ScienceOutdoors_FPV · 发布日期：2024-02-20 · 分类：各种资料

📑 目录

    通过jq命令行工具解析小红书无水印视频

    
                        import requests
                        import re
                        import json

                        link = 'http://xhslink.com/FvI7oE'
                        #将链接替换为需要下载的小红书视频URL

                        def work(url: str) -> dict:
                            r = requests.get(url)
                            if r.status_code == 200:

                                url_with_watermark = re.findall(r'<meta name="og:video" content="(.*?)">', r.text)
                                if url_with_watermark:
                                    url_with_watermark = url_with_watermark[0]
                                else:
                                    url_with_watermark = None

                                key = re.findall(r'{\"originVideoKey\":\".*?\"}', r.text)
                                if key:
                                    url_without_watermark = "http://sns-video-bd.xhscdn.com/" + json.loads(key[0])["originVideoKey"]
                                    #"http://sns-video-bd.xhscdn.com/"后为抓取的无水印链接
                                else:
                                    url_without_watermark = None
                                return {
                                    "url_with_watermark": url_with_watermark,
                                    "url_without_watermark": url_without_watermark
                                }
                            else:
                                print(f"status code: {r.status_code}")
                                return {
                                    "url_with_watermark": None,
                                    "url_without_watermark": None
                                }

                        print(work(link))

                        //脚本来自:iecho.cc
    20240329更新：这个脚本似乎被墙了，可能是因为小红书代码迭代的变动，现在仍可以手动操作，步骤是： //进入视频详情页，查看网页源代码，全局查找`originVideoKey`，复制`"originVideoKey":"spectrum\u002F1040g35830vr3bg1860005o6qr60o57fr83a7isg"`字段 //其中的`\u002F`代表他是Unicode编码的`/`，可以用`jq`命令来解码 //回到终端，启用jq命令，将上一步复制的字段拼接在下方代码对应的部分 
    
                        echo '{"originVideoKey":"spectrum\u002F1040g0jg3103tbmv45u005n287aa4fok1bgg0ktg"}' | jq
    得到 
    
                        {
                          "originVideoKey": "spectrum/1040g0jg3103tbmv45u005n287aa4fok1bgg0ktg"
                        }
    将其中的`"spectrum/1040g0jg3103tbmv45u005n287aa4fok1bgg0ktg"` 拼接在 `https://sns-video-bd.xhscdn.com/`尾部。得到无水印视频URL。 例如 `https://sns-video-bd.xhscdn.com/spectrum/1040g0jg3103tbmv45u005n287aa4fok1bgg0ktg`
